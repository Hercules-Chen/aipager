API 錯誤

HTTPcode意義呼叫端怎麼處理
400E_VALIDATION不符合 schema；detail 帶 Ajv 錯誤路徑修正後重送，不要重試
401E_AUTHtoken 錯誤、過期、被撤銷檢查 token 檔，重新發 token
403E_FORBIDDENtoken 權限不足（例如讀別台的信箱）不要重試
404E_NOT_FOUND任務、訊息、附件不存在不要重試
409E_CONFLICT狀態不允許此操作（例如更新已結束的任務）重新查詢狀態
409E_LEASE_LOST租約不符或已過期Worker 停止回報該任務，結果保留在本機
413E_PAYLOAD_TOO_LARGE超過大小上限改用附件或 Git
422E_PROFILE_UNKNOWN目標節點沒有宣告此 profile先 relay_list_nodes
422E_REQUIREMENT_UNMET指定節點的 os / arch / 標籤不符合 requires改目標或拿掉限制
409E_TARGET_UNAVAILABLE目標沒在線且 on_unavailable 為 confirm / reject；任務未建立，回應附 alternatives問使用者：排隊、改派或取消
422E_ENROLL_INVALID加入碼錯誤、過期、已使用或已撤銷請管理者重新建立加入碼
409E_NODE_EXISTSnode_id 已被使用，且加入碼沒有綁定這個 id換 node_id，或請管理者建立綁定該 id 的加入碼（重灌）
403E_NODE_NOT_ACTIVE節點為 pending / disabled，不能送或領任務請管理者核准或啟用
409E_META_CONFLICT修改 metadata 時 If-Match 版本已過期重新讀取後再改
422E_HOP_LIMIT / E_THREAD_LIMIT / E_BUDGET / E_SELF_TARGET防迴圈與預算限制交由人判斷，不要自動繞過
429E_RATE_LIMIT建立太頻繁依 Retry-After 等待
503E_UNAVAILABLEHub 正在關閉或 DB 忙碌指數退避重試（1、2、4、8、16 秒）

任務結果錯誤（task.result.error.code）

code產生者意義
E_TIMEOUTWorker / Hub超過 timeout_sec，程序已被終止
E_MAX_TURNSWorkerClaude 結果 subtype 為 error_max_turns
E_CLAUDE_EXITWorkerclaude 非 0 結束；stderr 末 50 行附在 detail
E_CLAUDE_NOT_FOUNDWorkerclaude_path 不存在或無法啟動
E_CLAUDE_AUTHWorkerstderr 顯示未登入或憑證無效（常見於 macOS 未登入時使用 login 模式）
E_REPO_NOT_ALLOWEDWorkerrepo url 不在 profile 的 allow_remote
E_WORKDIR_DIRTYWorker工作目錄有未提交變更，為避免覆蓋而拒絕執行
E_GIT_FAILEDWorkerfetch / checkout 失敗
E_PRE_COMMAND_FAILEDWorkerprofile 的 pre_commands 失敗
E_OUTPUT_SCHEMAWorker要求 json 輸出但不符合 schema；原始輸出仍附在 output
E_CANCELLEDWorker收到取消並已終止
E_LEASE_LOSTHubWorker 失聯且無重試次數
E_WORKER_CRASHWorkerWorker 重啟時發現上次中斷的任務
