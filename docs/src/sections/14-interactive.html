註冊 MCP（全機共用，信箱 main）

Windows
claude mcp add --scope user --env RELAY_AGENT=main relay -- node "C:\Program Files\ClaudeRelay\bin\relay-mcp.js" --mode interactive
macOS / Linux
claude mcp add --scope user --env RELAY_AGENT=main relay -- node /opt/claude-relay/bin/relay-mcp.js --mode interactive

依專案區分信箱（例如 ERP 專案用 erp@dev-pc），在專案根目錄放 .mcp.json：

專案層級 .mcp.json（Windows / POSIX）
spec/claude/mcp.project.windows.json
spec/claude/mcp.project.posix.json

同一個 repo 會在不同 OS 上開啟時，.mcp.json 不要寫死絕對路徑。改用使用者層級的 MCP 註冊（上方指令），專案層級只放 RELAY_AGENT 的差異；或把 .mcp.json 加進 .gitignore，各機各放一份。

未讀提示 hook

合併進使用者設定檔：Windows 為 %USERPROFILE%\.claude\settings.json，macOS / Linux 為 ~/.claude/settings.json。relay-hint 會讀 cwd 下 .mcp.json 的 RELAY_AGENT 決定查哪個信箱，沒有就用 main。

hooks 設定（Windows / POSIX）
spec/claude/settings.hooks.windows.json
spec/claude/settings.hooks.posix.json

實際使用

不需要記工具名稱，直接用自然語言：

  • 「把目前分支推上 Git，叫 build-pc 用 build profile 編譯這個 commit，等結果回來告訴我」
  • 「請 Mac 跑 iOS 的單元測試，跑完前我先繼續改 UI，有結果再提醒我」。筆電睡著的話，Claude 會先告訴你「macbook-hc 已 42 分鐘沒有回應」，問你要排隊、改派還是取消
  • 「現在有哪些機器在線？macbook 上次出現是什麼時候？」
  • 「看一下 relay 信箱，build-pc 問的問題幫我回：改用離線套件快取」
長任務不要佔住 session：每次等待最多 50 秒。Claude 可以先繼續別的工作，任務完成後下一次輸入時 relay-hint 會提示。如果希望互動 session 自動處理信箱，可用 /loop 10m 用 relay_inbox 檢查未讀，需要回覆的就處理並回覆，但會持續消耗用量，建議只在需要時開。
