Hub（Ubuntu 24.04 / 26.04）

Ubuntu 26.04 注意：Ubuntu 從 25.10 開始預設改用 Rust 版 coreutils（uutils）與 sudo-rs，26.04 LTS 預期沿用。install-hub.sh 只用 install、useradd、date 等常見參數，理論上相容，但仍列為實機驗證項目 T31。若遇到不相容，可先安裝 GNU 版 coreutils 再執行。
  1. 安裝並登入 Tailscale，記下 tailscale ip -4（例：100.101.102.103）
  2. 下載 Node 22 官方 tarball 解壓到 /opt/node-v22；確認 /opt/node-v22/bin/node -e "require('node:sqlite'); console.log('sqlite ok')"
  3. 發行檔放到 /opt/claude-relay，執行 /opt/node-v22/bin/npm ci --omit=dev
  4. sudo /opt/claude-relay/scripts/linux/install-hub.sh --allow-cidr 100.64.0.0/10：建立系統帳號、目錄與權限、systemd unit、防火牆規則
  5. 編輯 /etc/claude-relay/hub.json 的 listen.host 為步驟 1 的 IP
  6. sudo -u claude-relay /opt/node-v22/bin/node /opt/claude-relay/bin/relayctl.js admin init --config /etc/claude-relay/hub.json：初始化 DB、印出 admin token（只顯示一次，請存進你自己的 relayctl 設定）
  7. sudo systemctl enable --now claude-relay-hub，用 journalctl -u claude-relay-hub -f 觀察
  8. 驗證 T01、T22；Ubuntu 26.04 另做 T31

每台新機器的共同步驟（Worker 或互動機都一樣）

  1. 安裝 Tailscale 並加入同一個 tailnet；curl http://relay-hub:7300/api/v1/health 有回應
  2. 安裝 Git 與 Claude Code（原生安裝版），以要跑 Worker 的帳號執行一次 claude 完成登入
  3. 安裝 Volta，volta install node@22，確認 node -e "console.log('node-ok')"
  4. 放置發行檔並 npm ci --omit=dev
  5. 向管理者取得加入碼（Dashboard「新增機器」或 relayctl enroll create）
  6. relayctl join --hub http://relay-hub:7300 --code <加入碼>：自動檢查環境、取得 token、依平台寫好 node.json / token 檔（含權限）/ 只含 echo 的 profiles.json。只當互動機時加 --no-worker
  7. 要接任務的機器：relayctl service install（細節見下方各平台）
  8. 管理者在 Dashboard 核准；之後依需要編輯 profiles.json、為每個 profile 準備專屬 clone

Windows Worker

  1. 額外安裝 Git for Windows（Claude 的 Bash 工具需要）
  2. relayctl join 已把設定寫到 C:\ProgramData\ClaudeRelay\node\ 並以 icacls 限制 node.token
  3. 以系統管理員執行 relayctl service install：內部執行 register-worker-task.ps1（會詢問該帳號密碼，讓排程在未登入時也能執行）；也可手動執行該腳本
  4. 電源計畫：插電時睡眠設為「永不」
  5. 驗證 T03

macOS Worker

  1. 需要建置 iOS 的機器先裝 Xcode 與 Command Line Tools
  2. relayctl join 已把設定寫到 ~/Library/Application Support/ClaudeRelay/node/ 並 chmod 600；join 時建議加 --power laptop
  3. 若要重開機免登入：執行 claude setup-token，把 token 存成 claude-oauth.token（chmod 600），node.json 設 claude_auth.mode = "oauth_token"
  4. relayctl service install --mode agent（需登入）或 sudo relayctl service install --mode daemon --user <帳號>（免登入）會自動完成下列兩步。手動做法：把 plist 中的 USERNAME 換成實際帳號名稱。需要登入才執行時：放到 ~/Library/LaunchAgents/，執行 launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.claude-relay.worker.plist
  5. 免登入時：改放 /Library/LaunchDaemons/，加上 UserName，執行 sudo launchctl bootstrap system /Library/LaunchDaemons/com.claude-relay.worker.plist
  6. 要隨時能接任務：sudo pmset -c sleep 0（插電時不睡眠）
  7. 驗證 T04

Linux Worker

  1. relayctl join 已把設定寫到 ~/.config/claude-relay/ 並 chmod 600
  2. relayctl service install 會把 unit 複製到 ~/.config/systemd/user/claude-relay-worker.service 並執行下面兩步（linger 需要 sudo，會印出指令請你執行）
  3. sudo loginctl enable-linger $USER（登出與重開機後仍執行）
  4. systemctl --user daemon-reload && systemctl --user enable --now claude-relay-worker
  5. 用 journalctl --user -u claude-relay-worker -f 觀察，驗證 T05

互動機（任一 OS）

  1. 做共同步驟 1–6，join 時加 --no-worker（若這台也要接任務就不加，並做該平台的 Worker 步驟）
  2. 依 註冊 MCP 並合併 hooks 設定
  3. 驗證 T06–T08

relayctl 指令

指令用途
relayctl doctor印出 OS / 架構、設定檔路徑、node_id、hub_url、Node 與 claude 版本、登入模式、token 是否有效、時鐘差、資料目錄是否可寫；任一項失敗 exit code 非 0
relayctl doctor --encoding檢查設定與 Log 檔的編碼與換行
relayctl nodes節點清單（含 os / arch）
relayctl send --to worker@build-pc --profile echo --title "冒煙測試" --text "執行 hostname 與 whoami 並回報" --wait 120送任務並等待；可加 --requires-os linux
relayctl tasks --state running任務清單
relayctl show <task_id> --events任務詳情與進度
relayctl cancel <task_id>取消
relayctl msg --to main@dev-pc --text "…"送訊息
relayctl inbox --agent main讀信箱（不 ack）
relayctl approvals / approve <id> / deny <id> --note "…"審核（admin）
relayctl tail即時顯示 SSE 事件（admin）
relayctl trace <trace_id>合併追蹤
relayctl enroll create --name … --power laptop --role … --label k=v --ttl 24h建立加入碼（admin）
relayctl join --hub … --code … / relayctl service install|uninstall|status本機加入與服務管理
relayctl nodes show|set|history|rollback|approve|drain|disable|enable|retire節點管理（見 ）
relayctl admin backup / admin restore <file>備份與還原（還原需先停止 Hub）
