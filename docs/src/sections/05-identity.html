位址格式

寫法JSON 形式意義
worker@build-pc{"node":"build-pc","agent":"worker"}指定機器上的 Worker
worker@role:tester{"role":"tester","agent":"worker"}任一台宣告 tester 角色、在線、且符合 requires 的 Worker；先領先做
main@dev-pc{"node":"dev-pc","agent":"main"}dev-pc 上互動 session 的信箱
erp@dev-pc{"node":"dev-pc","agent":"erp"}dev-pc 上 ERP 專案的 session（專案層級 .mcp.json 設 RELAY_AGENT=erp）
human@hub{"node":"hub","agent":"human"}Dashboard 上的人（審核請求的收件者）
  • node_id：小寫英數與連字號，2–32 字元，正規式 ^[a-z0-9][a-z0-9-]{1,31}$
  • agent 名稱：1–32 字元。保留字 worker、human、hub
  • 任務的目的地只能是 worker；訊息的目的地可以是任何信箱
  • 封包中的 from 一律由 Hub 依 token 填入，呼叫端無法冒充

Token

種類前綴發給誰能做什麼有效期
adminrla_Dashboard、管理者的 relayctl全部，含審核、發 token、看所有 Log手動撤銷前有效
noderln_每台機器一把以該 node 身分心跳、領任務、送任務與訊息、讀自己 node 的信箱手動撤銷前有效
enrollmentrle_管理者建立，交給要加入的新機器只能呼叫一次 POST /enroll 換得 node token使用一次即失效；預設 24 小時過期
taskrlt_領任務時由 Hub 核發，只給該任務的 Claude session回報該任務的進度、結果、審核；建立子任務（hop + 1）任務結束後 5 分鐘失效
  • 格式：前綴 + 32 bytes 亂數（base64url）。Hub 只存 SHA-256 雜湊，明文只在建立時顯示一次
  • 傳遞：HTTP header Authorization: Bearer <token>；互動 session 另帶 X-Relay-Agent: main
