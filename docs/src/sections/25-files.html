本文件的程式碼區塊都是從下列檔案直接嵌入；章節編號、目錄、交叉引用由建置程式自動產生。修改請改原始檔後依序執行 node tools/validate-spec.js 與 node tools/build-doc.js，不要直接改產出的 HTML。

文件原始檔

檔案內容
docs/src/layout.html頁面外框：樣式、目錄、腳本

docs/src/sections/NN-<id>.html一章一個檔案，依檔名排序決定章節編號。開頭固定為 <section id data-title data-group>；交叉引用寫 <a data-ref="id"></a>，不要手寫編號
docs/claude-relay-design.html產出：可直接用瀏覽器開啟的完整 HTML
docs/artifact/claude-relay-design.html產出：發佈到 claude.ai 用的片段
