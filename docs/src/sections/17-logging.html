元件Log 位置
aipager-hub（Linux）/var/log/aipager/hub-yyyyMMdd.jsonl；啟動與崩潰訊息在 journalctl -u aipager-hub；DB 的 events 表作為稽核紀錄
aipager-worker各平台 Log 位置（見 ）下的 worker-yyyyMMdd.jsonl + 每個任務目錄的 worker.log
aipager-mcp同目錄 mcp-yyyyMMdd.jsonl（stdout 留給 MCP 協定，Log 一律寫檔或 stderr）
aipager-hint同目錄 hint-yyyyMMdd.jsonl
服務主控台輸出Windows：worker-console.log；macOS：plist 指定的 worker-console.log；Linux：journalctl --user -u aipager-worker
  • 等級由 log.level 或環境變數 AIPAGER_LOG_LEVEL（debug / info / warn / error）控制；每日輪替、單檔 50 MB、保留 30 天
  • token、密碼、連線字串一律遮罩（只顯示前綴與末 4 碼）
  • 每筆都帶 trace_id 與 os；aipagerctl trace <trace_id> 會合併 Hub 事件與已上傳的 stream log，不必登入各台機器翻檔

Chrome DevTools

  • Hub：在 Hub 機暫時以 AIPAGER_INSPECT_PORT=9229 啟動（只綁 127.0.0.1），從自己電腦以 ssh -L 9229:127.0.0.1:9229 hub 轉送後開 chrome://inspect
  • Worker：Windows 用 start-worker.ps1 -InspectPort 9230；macOS / Linux 用 AIPAGER_INSPECT_PORT=9230 start-worker.sh（已實測會印出 DevTools 連線位址）
  • Dashboard：未打包的原始碼，F12 直接看 Network（每個回應的 X-Trace-Id）與 Sources

症狀對照

症狀先看哪裡
Hub 啟動後連不上journalctl -u aipager-hub 是否持續出現綁定重試（Tailscale 未就緒或 listen.host 錯）；ufw status
節點顯示 offline該機 aipagerctl doctor；worker Log 的 heartbeat 錯誤；機器是否進入睡眠
任務一直 queued目標節點有沒有宣告該 profile；requires.os 是否沒有任何在線節點符合；max_concurrent 是否滿；concurrency_key 是否被鎖住
E_CLAUDE_AUTH 或 stderr 提到登入Worker 執行身分是否就是登入 Claude 的使用者；macOS 改用 oauth_token 模式；用同一身分手動跑 cmdline.txt 重現
Linux Worker 登出後停止是否執行過 sudo loginctl enable-linger <user>
筆電顯示 asleep闔蓋或睡眠時屬正常；若筆電明明開著：Worker 是否在跑（aipagerctl service status）、Tailscale 是否連線
桌機 / 伺服器常被判 asleep網路不穩或機器忙到心跳延遲；在 metadata 調高 presence.asleep_after_sec，並查 worker Log 的 heartbeat 錯誤
aipagerctl join 失敗join 會先跑 doctor 並逐項列出；E_ENROLL_INVALID 請重新建立加入碼；E_NODE_EXISTS 改 --node-id
改了 metadata 沒生效aipagerctl nodes history <id> 確認新版本存在；路由用的是 Hub 端資料，下一次領任務即生效；Worker 本機快取在 15 秒內更新
派工一直被要求確認目標不在線（看 aipagerctl nodes）；自動化流程請改用 on_unavailable=queue
launchd / systemd 下找不到 node 或 claude服務設定檔的 PATH；start-worker.sh 會在第一行印出實際使用的 node 路徑
任務卡在 waiting_approvalDashboard 審核佇列；MCP_TOOL_TIMEOUT 是否大於審核逾時
結果 summary 是空的或很怪metrics.result_source；任務目錄的 stream.jsonl 最後一筆 type=result
中文亂碼stream.jsonl 是否為 UTF-8；Windows 上被呼叫的 .ps1 是否設定 [Console]::OutputEncoding 為 UTF-8；.bat 是否為純 ASCII
同一 repo 在不同 OS 結果不同換行（.gitattributes）、大小寫敏感的檔名、平台專屬指令
互動 session 沒有未讀提示hint Log；claude --debug 看 hook 是否執行；/hooks 確認設定
Windows Worker 開機後沒起來工作排程器「AIPager Worker」的上次執行結果；worker-console.log；-1073741819 表示 Node native crash，先查 Node 執行環境
