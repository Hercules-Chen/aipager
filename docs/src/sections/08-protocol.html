任務、進度、結果、訊息、審核全部使用同一個封包格式，只有 kind 與 payload 不同。完整 JSON Schema（draft 2020-12）見本節最後；所有範例都已用 Ajv 驗證通過。

傳遞保證

  • 信箱：至少送達一次。讀取後需 ack（MCP 工具預設讀取即 ack），沒 ack 的下次還會出現
  • 任務執行：預設最多一次。max_attempts=1，因為編譯、推送、改檔都有副作用。需要重試的唯讀任務才調高
  • 順序：同一信箱依 created_at、id 排序；不保證跨信箱的全域順序
  • 冪等：(from.node, idempotency_key) 唯一，24 小時內重送回傳原結果（HTTP 200 而非 201）

版本規則

  • v 為 主版.次版。新增選填欄位只升次版。頂層未知欄位會被拒絕（避免打錯字靜默失效），擴充資料請放 meta
  • 破壞性變更升主版，並同時提供 /api/v2，舊版至少並存一個開發階段
