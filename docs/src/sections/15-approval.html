Dashboard 頁面

頁面內容
節點在線狀態（含沉默多久）、顯示名稱、機器類型、角色、標籤、OS / 架構、執行中任務、排隊等它的任務數；可依在線狀態、角色、標籤篩選
新增機器填 preset（名稱、類型、角色、標籤）與有效期 → 顯示加入碼與三個平台的 join 指令（可複製）
待核准新 join 的機器與它回報的 facts；核准前可修改 metadata
節點詳情metadata 編輯表單（送出時帶 If-Match）、修改歷史與還原、facts、profiles（含錯誤）、7 天在線時間軸、drain / disable / retire 按鈕
任務依狀態或 OS 篩選；每列有狀態標籤、來源 → 目的、profile、耗時、花費
任務詳情envelope、進度時間軸（SSE 即時）、結果、artifact 下載、原始 stream.jsonl 檢視、「複製 cmdline」
審核佇列工具名、參數（可展開）、風險等級、剩餘時間；按鈕：核准、拒絕（附說明）、修改參數後核准
Thread / Trace一串任務與訊息的時序圖；trace 頁合併所有事件
  • 語系：/ui/i18n/zh-TW.json、/ui/i18n/en.json，依瀏覽器語言或右上角切換
  • 網址加 ?debug=1 顯示每個畫面背後的原始 JSON 與 trace_id
  • 不打包、不壓縮，原生 ES modules，Chrome DevTools 可以直接下中斷點
  • admin token 輸入一次後存在 sessionStorage，關分頁即清除
  • 任何裝了 Tailscale 的裝置（包含手機）都能開 Dashboard 審核

通知管道

審核請求與任務失敗可透過 webhook 通知（hub.json 的 webhooks），格式支援 ntfy、teams、slack、generic（原始 envelope）。通知內只放標題、節點、Dashboard 連結，不放參數內容。
