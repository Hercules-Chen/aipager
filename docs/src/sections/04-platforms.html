平台路由

  • 任務可帶 requires: {"os":["macos"], "arch":["arm64"]}；只有心跳回報符合的節點能領取
  • 目標是指定節點但平台不符時，建立當下就回 422 E_REQUIREMENT_UNMET；目標是角色時，任務在佇列等符合的節點上線
  • relay_list_nodes 會回傳每台的 os / arch，Claude 派工前可以自行判斷

跨平台內容規則

  • 封包中的路徑一律是相對路徑、以 / 分隔；Worker 在本機轉換
  • Worker 產生的檔案一律 UTF-8 無 BOM、LF 換行；只有 Windows 的 .bat / .ps1 例外
  • artifact 的 glob 由 Worker 自行比對且區分大小寫，不依賴檔案系統（macOS 預設不分大小寫、Linux 區分），三個平台結果一致
  • 建議所有被 Worker 使用的 Git repo 加 .gitattributes：* text=auto eol=lf、*.bat text eol=crlf、*.ps1 text eol=crlf，讓不同 OS 的 Worker 看到相同內容
  • system prompt 會告訴 Claude 目前的 OS 與 shell，讓它選對指令與路徑語法
