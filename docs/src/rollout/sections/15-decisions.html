#問題影響哪個階段建議
Q4Git server 是哪一套？build-pc 用 SSH key 還是 HTTPS 憑證？R3（第一個實際編譯流程）SSH，並為 Worker 帳號設定唯讀 deploy key
Q7審核與失敗通知要送到哪裡？R7先只看 Dashboard；常用手機的話，ntfy 最簡單
N1是否啟用 GitHub Actions CI（B01）？私人 repo 會用到 Actions 分鐘數，macOS 環境計費較高R2 之前啟用；macOS 只在 PR 合併到 main 時跑
N2Hub 放哪一台？能否在 Tailscale 改名為 aipager-hub？R1選一台不睡眠的 Ubuntu 機器，改名為 aipager-hub
N3Windows 安裝位置：C:\Program Files\AIPager（升級要系統管理員）或使用者目錄R2維持 Program Files（與規格一致，避免一般程序改動程式檔）
N4Worker 上的 Claude Code 要自動更新，還是統一手動升級？R2 起手動升級，升級前先跑 npm run test:real-claude。關閉自動更新的實際設定方式要在 R2 實機確認
N5admin token 由誰保管？是否需要多把（例如每個管理者一把）？R1每位管理者一把，各自用 admin token 建立，方便個別撤銷

回覆這些問題後，Claude 會更新本文件與設計規格的待確認事項，並依決定調整後續步驟。
