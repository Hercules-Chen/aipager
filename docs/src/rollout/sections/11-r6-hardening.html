T17 Hub 重啟中任務不中斷

對 build-pc 送 longrun（ping -n 180 127.0.0.1），開始執行後在 Hub 機 sudo systemctl stop aipager-hub，1 分鐘後 sudo systemctl start aipager-hub。預期任務最終 succeeded，build-pc 的 worker Log 有結果補送紀錄。

T18 Worker 停止時任務排隊

在 linux-box 執行 systemctl --user stop aipager-worker，從你的電腦以 --on-unavailable queue 送任務給它，2 分鐘後 systemctl --user start aipager-worker。預期 Dashboard 首頁先出現 linux-box 與卡住的任務，啟動後任務完成。
