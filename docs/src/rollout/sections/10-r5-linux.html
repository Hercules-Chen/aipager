目標：一台 Linux 當 tester（例如 E2E），驗證跨平台路由與流水線。

1. 安裝與加入

Linux：終端機（以要跑 Worker 的帳號）
curl https://get.volta.sh | bash
# 重開終端機
volta install node@22
curl -fsSL https://claude.ai/install.sh | bash
claude --version
git clone https://github.com/Hercules-Chen/aipager.git ~/aipager
cd ~/aipager && npm ci --omit=dev
node bin/aipagerctl.js join --hub http://aipager-hub:7300 --code ape_加入碼 --node-id linux-box --label browser=chromium
node bin/aipagerctl.js doctor
sudo loginctl enable-linger "$USER"
node bin/aipagerctl.js service install
journalctl --user -u aipager-worker -n 20 --no-pager

加入碼請以 --role tester 建立。依 N4 關閉 Claude Code 自動更新（見 ）。service install 會把 unit 寫到 ~/.config/systemd/user/，產生的 unit 已在自動化測試中通過 systemd-analyze verify。

2. 驗收

  • T05：同 T03，改送到 worker@linux-box，內容「讀取 /etc/os-release 並回報」
  • T19：macbook-hc 與 linux-box 都是 tester 時，send --to worker@role:tester --requires-os macos 只能由 Mac 領走；對 build-pc 送 --requires-os linux 應立即回 E_REQUIREMENT_UNMET
  • T20：需要待辦 B02（讓 aipagerctl 與 MCP 能送出含 then 的任務）完成後才能從工具執行；Hub 端的鏈結邏輯已有自動化測試
