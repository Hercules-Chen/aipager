目標：Windows build-pc 以「登入 Claude Code 的那個 Windows 帳號」常駐 Worker，重開機不登入也能接任務。這是 Windows 程式路徑第一次在真機上執行，預期可能遇到問題，每一步都要看輸出。

0. 先讓你的電腦以互動機加入

aipagerctl send 必須從一台已加入的機器發出。先在你的電腦（R1 步驟 4 那台）建立加入碼並以 --no-worker 加入：

你的電腦（repo 目錄）
node bin/aipagerctl.js enroll create --name "我的開發機" --power laptop --auto-approve --hub http://aipager-hub:7300
node bin/aipagerctl.js join --hub http://aipager-hub:7300 --code ape_上一行的加入碼 --no-worker --node-id dev-pc
node bin/aipagerctl.js doctor

機器類型依實際情況填 laptop 或 desktop。doctor 會因為沒有 Worker 而略過 claude 檢查，其他項目應為 OK。

1. build-pc 前置安裝

build-pc：一般 PowerShell，以要跑 Worker 的帳號
winget install --id Tailscale.Tailscale -e
winget install --id Git.Git -e
winget install --id Volta.Volta -e
# 關閉並重開 PowerShell，讓 PATH 生效
volta install node@22
node -e "console.log('node-ok')"
irm https://claude.ai/install.ps1 | iex
claude --version
  • Tailscale 登入同一個 tailnet；curl.exe http://aipager-hub:7300/api/v1/health 要有回應
  • 執行一次 claude，用 Max 帳號登入後 /exit（Q5）
  • Git for Windows 是 Claude 的 Bash 工具所需，不能省略
  • node -e 若回傳 -1073741819，是 Node 原生崩潰，先處理 Node 安裝本身
  • 依 N4 關閉 Claude Code 自動更新，做法見 的「Claude Code 升級」；步驟 3 建立 profile 時記得加上 env

2. 安裝 AIPager 並加入

build-pc：系統管理員 PowerShell
git clone https://github.com/Hercules-Chen/aipager.git "C:\Program Files\AIPager"
cd "C:\Program Files\AIPager"
npm ci --omit=dev

在你的電腦建立加入碼：

你的電腦
node bin/aipagerctl.js enroll create --name "Build PC" --power desktop --role builder --hub http://aipager-hub:7300
build-pc：一般 PowerShell（登入 Claude 的帳號）
cd "C:\Program Files\AIPager"
node bin\aipagerctl.js join --hub http://aipager-hub:7300 --code ape_加入碼 --node-id build-pc
node bin\aipagerctl.js doctor

預期：join 顯示「狀態 pending（等待管理者核准）」，設定寫在 C:\ProgramData\AIPager\node\，doctor 中 claude、hub、token 皆為 OK。到 Dashboard「待核准的機器」按核准，或在你的電腦執行 node bin/aipagerctl.js nodes approve build-pc --hub http://aipager-hub:7300。

3. 測試用 profile

join 只建立了唯讀的 echo profile。T11、T13 需要能跑長時間指令的 profile，編輯 C:\ProgramData\AIPager\node\profiles.json，在 profiles 裡加入：

profiles.json 內新增（JSON 中反斜線要寫兩個）
"longrun": {
  "description": "測試用：長時間指令（T11 取消、T13 逾時）",
  "workdir": "C:\\ProgramData\\AIPager\\worker\\sandbox",
  "model": "haiku",
  "permission_mode": "default",
  "allowed_tools": ["Bash(ping:*)", "Bash(sleep:*)"],
  "approval": { "auto_deny": ["*"] },
  "max_turns": 5,
  "timeout_sec": 900
}

存檔後不用重啟：Worker 會自動重新載入，Dashboard 的節點頁會出現 longrun；如果格式錯誤，節點頁會顯示紅色的 profiles.json 錯誤並沿用舊設定。

4. 安裝為開機自動執行

build-pc：系統管理員 PowerShell（會詢問 Windows 密碼）
cd "C:\Program Files\AIPager"
node bin\aipagerctl.js service install
powercfg /change standby-timeout-ac 0
Get-Content C:\ProgramData\AIPager\logs\worker-console.log -Tail 20

預期：console log 印出 config、node_id、hub_url、claude 版本；Dashboard 節點頁 build-pc 為 online、windows/x64。

驗收

你的電腦：T03、T11、T13
node bin/aipagerctl.js send --to worker@build-pc --profile echo --title 冒煙 --text "執行 hostname 與 whoami 並回報" --wait 180
node bin/aipagerctl.js send --to worker@build-pc --profile longrun --title 取消測試 --text "用 Bash 執行 ping -n 300 127.0.0.1"
node bin/aipagerctl.js cancel 上一行的task_id
node bin/aipagerctl.js send --to worker@build-pc --profile longrun --title 逾時測試 --text "用 Bash 執行 ping -n 300 127.0.0.1" --timeout 60s --wait 300
  • T03：結果 succeeded、來源 submit_tool、summary 含 build-pc 的主機名稱
  • T11：取消後 60 秒內變 cancelled；工作管理員中不能留下 claude.exe、ping.exe（這是 Windows 的 taskkill 路徑第一次實測）
  • T13：約 60 秒後 failed、E_TIMEOUT
  • T16：重開 build-pc、不要登入，等 2 分鐘後重跑 T03 那一行

已知風險（這一階段要特別看）

風險徵兆處理
排程工作找不到 node（Volta 的 PATH 沒載入）worker-console.log 出現「node 不是內部或外部命令」回報後改成在 start-worker.ps1 使用 node 的絕對路徑，或改用 Node 官方 MSI 安裝到全機
未登入時讀不到 Claude 憑證T16 失敗，錯誤碼 E_CLAUDE_AUTH改用 claude setup-token 與 claude_auth.mode = "oauth_token"，或排程改為「登入時」觸發
.ps1 在 Windows PowerShell 5.x 解析失敗console log 有 ParserError貼回錯誤，修正腳本並補 CI 的 pwsh 解析檢查
taskkill 沒有終止整個程序樹T11 後仍有 claude.exe貼回 worker Log 的 task.killed 紀錄與工作管理員截圖

退回：系統管理員 PowerShell 執行 node bin\aipagerctl.js service uninstall，Dashboard 上把 build-pc 設為 disabled。
