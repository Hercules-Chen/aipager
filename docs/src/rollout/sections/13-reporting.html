失敗時附上診斷檔

以下指令只打包 Log 與任務目錄，不含 node.token（任務的 token 檔在任務結束時已刪除）。任務目錄包含送給 Claude 的 prompt 與 Claude 的輸出，可能有程式碼，分享前請自行確認。

Windows（PowerShell）
Compress-Archive -Path C:\ProgramData\AIPager\logs, C:\ProgramData\AIPager\worker\tasks -DestinationPath "$env:USERPROFILE\Desktop\aipager-diag.zip" -Force
macOS
tar -czf ~/Desktop/aipager-diag.tgz -C ~/Library/Logs AIPager -C "$HOME/Library/Application Support/AIPager" worker/tasks
Linux Worker
tar -czf ~/aipager-diag.tgz -C ~/.local/state aipager/logs aipager/worker/tasks
Hub
journalctl -u aipager-hub --since "2 hours ago" --no-pager > ~/hub-journal.txt
sudo tar -czf ~/aipager-hub-diag.tgz /var/log/aipager ~/hub-journal.txt

只想看單一任務時，把 Worker 任務目錄中的 cmdline.txt、stderr.log、result.json 貼上通常就足夠；cmdline.txt 可以直接在該機器手動重跑，重現 Claude 端的問題。

結果怎麼記錄

  1. Claude 依你的回報更新 spec/tests/test-plan.json 中該項的 status（pass / partial / fail / blocked）與 last_run（日期、機器與作業系統、說明）
  2. 有程式修正時補自動化測試，在 Linux 重跑 npm test
  3. 重新建置文件：設計規格的驗證計畫、本文件各階段的測試狀態都會自動更新
  4. 開該階段的分支與 PR；PR 說明列出本次變更的測試項目與結果
