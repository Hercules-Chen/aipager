目標：一台常駐開機的 Ubuntu 24.04（或 26.04）跑 Hub，其他機器透過 Tailscale 用 http://aipager-hub:7300 連到它。詳細設計見規格的 部署 章節。

1. Tailscale 與機器名稱

Hub 機
sudo apt-get update && sudo apt-get install -y git curl xz-utils
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
tailscale ip -4

在 Tailscale 管理頁把這台機器改名為 aipager-hub，其他機器才能用這個名稱連線。若不改名，之後所有指令中的 aipager-hub 都換成實際的 MagicDNS 名稱或 100.x 位址。

2. Node.js 22（固定路徑）

Hub 機（x64；ARM 主機把 linux-x64 換成 linux-arm64）
curl -fsSLO https://nodejs.org/dist/v22.23.4/node-v22.23.4-linux-x64.tar.xz
sudo mkdir -p /opt/node-v22
sudo tar -xJf node-v22.23.4-linux-x64.tar.xz -C /opt/node-v22 --strip-components=1
/opt/node-v22/bin/node -e "require('node:sqlite'); console.log('sqlite ok')"

預期：最後一行印出 sqlite ok（前面可能有一行 ExperimentalWarning，屬正常）。

3. 安裝 AIPager 與 Hub 服務

Hub 機
sudo git clone https://github.com/Hercules-Chen/aipager.git /opt/aipager
cd /opt/aipager && sudo env PATH=/opt/node-v22/bin:$PATH npm ci --omit=dev
sudo /opt/aipager/spec/scripts/linux/install-hub.sh --allow-cidr 100.64.0.0/10

接著編輯設定：

Hub 機
sudoedit /etc/aipager/hub.json
  • listen.host：改成步驟 1 的 tailscale ip -4 結果
  • public_base_url：http://aipager-hub:7300（加入碼畫面產生的指令會用它）
  • webhooks：改成 []。依 Q7 決定不推播，只用 Hub 查詢；範本裡的 ntfy 位址只是範例，留著只會產生連線失敗的 Log
Hub 機：建立 admin token 並啟動
sudo -u aipager /opt/node-v22/bin/node /opt/aipager/bin/aipagerctl.js admin init --config /etc/aipager/hub.json
sudo systemctl enable --now aipager-hub
journalctl -u aipager-hub -n 20 --no-pager

預期：admin init 印出一次 apa_...，請立刻存到密碼管理工具；journal 中有 [hub] listening on http://100.x.x.x:7300。

4. 在你的電腦設定管理工具與 Dashboard

在你平常用的電腦（之後也會是 R3 的開發機）clone 本 repo 並 npm ci，然後：

你的電腦（repo 目錄）
curl http://aipager-hub:7300/api/v1/health
node bin/aipagerctl.js admin save-token apa_貼上剛才的token --hub http://aipager-hub:7300
node bin/aipagerctl.js admin backup --hub http://aipager-hub:7300

瀏覽器開 http://aipager-hub:7300/ui/，貼上 admin token 登入，首頁四個區塊都應該是空的。

其他管理者（N5）：每人各自建立一把 token，不要共用。以已登入的管理工具執行 node bin/aipagerctl.js admin token --label 管理者名稱，把印出的 token 交給對方，對方再於自己的電腦執行 admin save-token。

驗收

  • T01：除了 curl，也確認回應中的 version 為 0.5.0
  • T22 在 R1 只做「備份」：/var/lib/aipager/backup/ 出現 aipager-*.db；還原演練放在

出問題時

症狀先看
journal 一直出現 cannot bind ... yetlisten.host 是否等於 tailscale ip -4；Tailscale 是否已連線
其他機器 curl 連不上sudo ufw status 是否有 7300 規則；兩台是否都在同一個 tailnet；MagicDNS 名稱是否正確
install-hub.sh 在 26.04 失敗把完整輸出貼回（這正是 T31 要驗證的）。必要時依 Ubuntu 官方說明暫時切回 GNU coreutils 後再試，並記錄是哪一行失敗

退回：sudo systemctl disable --now aipager-hub。資料在 /var/lib/aipager，不會被刪除。
